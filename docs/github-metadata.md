# GitHub repository settings

What the repository's About box and social preview are set to, so they can be set again.

- **Description:** Your Mac's Claude Code and Codex sessions, on your phone: chat, answer prompts, pick up where the terminal left off. Self-hosted, no account.
- **Website:** none yet.
- **Topics:** `claude-code`, `tmux`, `self-hosted`, `pwa`, `react-native`, `macos`, `remote-control`, `ai-agents`, `mobile`
- **Social preview:** [`docs/screens/social-preview.png`](screens/social-preview.png), 1280 × 640, made with the other
  screenshots by `pnpm --filter workoffdesk screens`.
- **Dependabot:** version updates are held at `open-pull-requests-limit: 0` in `.github/dependabot.yml`
  while the repository is private; take both lines out when it goes public.
- **Features:** Issues on; Discussions off; Wiki off; private vulnerability reporting on (Settings → Security).

# 使用

[English](usage.md) · 简体中文

## 会话列表

登录后，看到的是 Mac 上正在跑的会话，排得像聊天列表：每行是会话名、最近一次变化的时间、Claude 最后说的话。
会话按项目分组：一个 git 仓库连同它所有的 worktree 算一个项目，组头是主目录的名字;在 worktree 或仓库里某个子目录的会话，
会话名旁边标出那个目录;不在 git 里的目录自成一个项目。只有一个项目时不显示组头。**设置 → 会话列表 → 不分组**
就全部排在一起，每行标出所在项目;每台手机、每个浏览器各记各的。
Claude 在干活时徽标写**运行中**,等你时写**等你确认**,说了你还没看的写**未读**。底部的搜索框按名字或目录筛。

会话按对话内容起名：用 Claude Code 或 Codex 给这个对话起的标题，对话聊到别的事，标题跟着变;还没有标题时用
目录名。把一行往左滑出**改名**,或者在会话里点顶栏的标题;在 Claude Code 里用 `/rename` 也能改，以后改的那个为准。
名字存在 Mac 上，各设备看到的都一样;Claude Code 的 `/resume` 列表和 Codex 里，这个对话也改成这个名字。

把一行往左滑出**置顶**:置顶的会话固定在列表最上面，底色和别的行不一样，后置顶的在上面，别的会话怎么跳都不影响它们。
置顶存在 Mac 上，各设备都一样;会话结束了、接着聊了，都还是置顶。同一个位置有**取消置顶**。

Claude 或 Codex 会话结束后仍留在列表里，不管是你结束的、Agent 自己退出的，还是 Mac 重启了：它挪到列表最后的**已结束**一组，头像变淡，打开是存在
Mac 上的那段对话，点**接着这个对话**就在同一个会话里接着聊。Claude Code 删掉对话记录之后(默认 30 天，
`cleanupPeriodDays` 设得更长则更久)它也还在，只是只能看、不能接着聊了。把一行往左滑(或者长按),运行中的有
**结束会话**,已结束的有**删除**;删除只是从 WorkOffDesk 里拿掉，Claude 或 Codex 自己的记录原样不动。

⊕ 旁边的时钟按钮打开 **Mac 上的对话**:Mac 上还留着的其他 Claude Code 和 Codex 对话，多久以前的都有，按天分组，
可以搜索;点一个先看，再接着聊。

## 新开或续上

顶上的 ⊕ 按钮有这几项：

- **在项目里新开 Claude**:选一个目录(`pinnedDirs` 里列的目录总会出现),Claude 就在那里启动。
- **续上最近的对话**:列出 Mac 上最近的 Claude 和 Codex 对话，可以搜索，每个都带着你在里面最后问的话;Codex
  的标着 **Codex**。程序经 SDK
  起的会话收在**自动任务的会话**下面。打开一个对话先是只读的;点**在手机上接着聊**就在这边接着聊。文件夹已经
  不在 Mac 上的对话(比如 worktree 删掉了)会直接说明，不能接着聊。
- **在项目里新开 Codex**:Mac 上装了 [Codex](https://github.com/openai/codex) 时才有。

### 从 Mac 上接管

还在 Mac 终端里开着的对话，会标着**电脑上开着**、**电脑上在干活**、**电脑上在等你确认**或
**电脑上有后台命令在跑**。接管就是让那个终端里的
Claude 或 Codex 退出，在这边的会话里接着跑;那个终端会告诉你怎么接回来。接管过来的 Claude 带着那个终端的环境变量;
Codex 则改在本服务的 Codex app server 里跑命令。

- 开着：点**接管到手机**。
- 在干活：**等这一步做完再接管**,或者**立即接管（打断这一步）**。
- 在等你确认：马上接管;那个确认会作废，接上后让它重做这一步。
- 有后台命令在跑:Claude 这一轮已经答完，只剩它起的命令还在跑。直接接管，那些命令会一起停掉;
  在等「这一步做完」的接管这时也会接上。

用 `workoffdesk claude` 启动的 Claude、用 `workoffdesk codex` 启动的 Codex 本来就是这边的会话，不用接管。
开在编辑器或 Codex App 里的 Codex 对话不能接管，先在那边关掉。一个会话的对话如果同时还在 Mac 的终端里开着，
会话里输入框上方会提示：退出那边的 Claude,或者改用 attach 接上这个会话。

### Codex 会话

Codex 会话在 Mac 上跑 Codex 自己的终端界面，手机驱动的是同一个对话：聊天、权限确认卡片、停止、排队、图片、
通知，和 Claude 一样。Codex 问你的问题用**看屏幕**或在 Mac 上回答。`/` 命令列表、模型 / 权限 / 思考强度菜单
和回退是 Claude Code 才有的，Codex 会话里没有。

## 聊天

Claude 会话显示成它的对话，从 Claude Code 的 transcript 读出来：你的消息、按 Markdown 渲染的 Claude 回复、
折叠起来的工具调用(点开看完整命令和输出)。往上翻会接着加载更早的。手机会存一份读过的内容，再打开会话是瞬间的。

- 别的 Claude 会话发来的消息显示成「收到 … 的消息」;点开后有**去那个会话**,发消息的会话还在 Mac 上运行时就跳过去。
- 子 agent 的调用(Agent,旧版 Claude Code 叫 Task)点开后有**看它做了什么**:子 agent 自己的对话，只读，它还在跑时跟着更新。
- Claude 按任务清单干活时，有一条进度栏写着做到第几项。输入框空着时，发送键的位置换成**停止**,作用和 Esc 一样，
  打断它。
- 在后台跑的命令和 Agent 列在一条栏里，点开就是 `/tasks`。
- Claude 在前台跑一条命令时，你发的消息要等它跑完才会被读到。输入框上方会有一条栏说明这一点，并写出是哪条命令，
  点**后台执行**就把这条命令转到后台(相当于在 Mac 上按 Ctrl+B),Claude 马上就能读到你的消息。
- 回复下面的**朗读**用手机的语音把它读出来。
- 你最后一条消息下面的**回退**打开 Claude Code 自己的回退点列表。
- 聊天显示不出 Claude 在等什么的时候，点**看屏幕**,把 Mac 上的屏幕以文字显示出来。
- Claude 因为账号额度用完停下时，提示写着**额度用完了**。Mac 上还有别的能选的 Claude 账号(见[这台 Mac](#这台-mac))
  时，点**换个账号接着跑**会列出它们;选一个，就在 Mac 上选它，先把这个会话搬过去(从终端接管来的也搬),
  再像在「这台 Mac」上一样把其他开着的会话搬过去;这个会话搬好后再替你发一句「继续」。Mac 终端里如果也开着
  同一个对话，那边的 Claude 会先被退出，除非它正在干活;这个会话搬不了时，列表里会写明原因;如果是因为这边或那边
  正在干活，会给你**现在就换（会打断它）**和**等它停下再换**两个按钮。会话菜单里的**换 Claude 账号**随时都能打开这个列表。停着的时候直接打字发送，也会先问要不要换，换好再发出去;关掉列表，
  这句话会回到输入框。没有别的账号时，提示会说怎么登录另一个。
- 这个对话在 Mac 的终端里也开着时，输入框上方有一条提示;点**退出那边的 Claude**就把那边的 Claude 退掉(它正在干活时会先问你)。

## 回答 Claude

- **提问和权限确认**变成一张选项卡片。权限确认点一下就回答；提问的选项点一下是选中，按**提交**才发出去，
  点错了不算数。两种都由 Mac 重新读屏核对，选项没变才按。**自己写一个回答**只把光标移过去，回答在输入框里写。
- **多选题**在卡片里勾选，一次发出去。
- 斜杠命令打开的**面板**(`/usage`、`/config`、`/model`……)显示成一张卡片，开着时输入框上方还有一条提示栏。
  **关闭 (Esc)** 关掉它。面板开着时，你发的内容会留在输入框里，因为它会进面板而不是给 Claude。

## 发送

- 在输入框里打字。上面的快捷键条有 Esc、Tab、粘滞的 Ctrl、方向键、^C、粘贴和回车。
- **按住说话**:说的字边说边显示;松手发送，上滑到 ✕ 取消，上滑到**转文字**先改再发。用的是浏览器自带的语音
  识别，不会把声音传到 Mac。
- **图片、视频和文件**:用输入框旁边的按钮添加，每个最大 4 GB;在浏览器里也可以把截图直接粘贴进输入框。它们存到 Mac 上，路径随你的消息一起发给
  Claude。上传的文件 30 天后删除。
- 打 `/` 列出这个会话里 Claude 能用的斜杠命令;打 `@` 列出它所在目录的文件。
- 输入框下面的胶囊显示用掉了多少上下文，还能切换模型、权限模式和思考强度。

## 排队的消息

Claude 在干活时你发的内容，直接进 Claude 自己的队列，等它下一步时读。Claude 正在启动、在问你问题、在压缩
上下文、或者已经结束时，消息先按顺序存在 Mac 上，等它能接收了再送进去。两种都列在输入框上方;存在 Mac 上的
可以修改、调整顺序或删掉。

## 通知

把网站添加到主屏幕，从主屏幕打开，再在设置里打开**推送通知**。Claude 等你确认、或者一轮做完时会通知你。
iPhone App 见 [iPhone App](ios-app.zh-CN.md)。在 iPhone App 里
点通知，不管当时在哪一页，都会在会话列表上打开那个会话，返回就回到列表;正在看的就是那个会话时，页面不动。

## 设备和密码

设置里列着**已登录的设备**;点**吊销**,那台设备下一次请求就会退出登录。Passkey 在同一页添加和删除。
忘了密码?在 Mac 上再跑一次 `workoffdesk setup`:设一个新密码，所有设备退出登录。

## 这台 Mac

设置 → **这台 Mac** 显示 `doctor` 在 Mac 上的检查结果，每个没通过的都带着修复命令(点一下复制),还有版本、保留的
各个发布，以及服务日志里最近的警告和错误(同一条重复出现的只列一次，写着出现了几次),点开看详情。**重启**会重启服务，不会结束会话;**回滚**回到上一个发布，
要再点一次确认，确认时写明回到哪个版本。页面会等服务回来，再告诉你结果。两者都要求服务是装好的服务在跑，
不是 `workoffdesk serve`。

Mac 上登录了不止一个 Claude 账号时(每个账号一个配置目录，由 `CLAUDE_CONFIG_DIR` 选),页面会在 **Claude 账号**
下列出它们，每个都带着它的会话最近一次报的 5 小时和 7 天额度。点一个，之后从手机或网页开的会话就用它跑，
新开的和续上的对话都一样;从终端接管的会话沿用那个终端的账号。只有和 `~/.claude/projects`
共用对话的账号才能选，这样每段对话都能在它上面续上;没共用或已退出登录的账号会写明原因。

已经开着的会话在你搬之前不换账号：有会话还在别的账号上时，账号列表下面会写明有几个，并给出**搬过去**,搬到打勾的账号。
每个会话都在两轮之间搬：停在提示符的马上搬，还在干活的等这轮回复完、你发的消息都进去了再搬。搬就是退出它的
Claude,在同一个窗口里用选中的账号重新启动，续上同一段对话;这期间发的消息先等着，启动后再发进去。搬完之前，页面会写明
正在搬几个，一直等到搬完。从终端开的会话不搬。

在 Mac 上也能做同样的事：菜单栏 App 的 **Claude 账号** 一节，以及命令行：

```bash
workoffdesk account                       # 列出账号，打勾的是在用的，以及还在别的账号上的会话
workoffdesk account use <邮箱|目录>        # 选一个;加 --move 顺便把开着的会话搬过去
workoffdesk account move                  # 把开着的会话搬到在用的账号
```

## 在 Mac 上

```bash
workoffdesk attach        # 选一个会话
workoffdesk attach <id>   # 直接接上那一个
workoffdesk claude        # 在当前目录开一个 Claude 会话，并接上
workoffdesk claude --resume <id>   # 同上，续上那个对话
workoffdesk codex         # 在当前目录开一个 Codex 会话，并接上
workoffdesk codex --resume <thread id>   # 同上，续上那个 thread
```

在会话里点 ⋯ → **在电脑上继续**,会显示它的 `attach` 命令，点一下复制。接的是同一个 tmux 会话，手机和 Mac
可以同时在上面。`Ctrl-b d` 脱离，会话继续跑。Mac 上没有终端接着时，
手机会把窗口设成 100×50,让对话框能完整显示;一旦有终端接上，窗口就跟着那个终端的大小。

# 隐私

[English](privacy.md) · 简体中文

## WorkOffDesk 收集什么

什么都不收集。没有我们的账号，没有统计分析，没有广告，也不追踪。WorkOffDesk 是你跑在自己 Mac 上的一个服务器，
加上连它的 App;你在里面做的事，只在你的手机和你的 Mac 之间。

## 留在手机上的

- 你 Mac 的地址，和它给 App 的登录凭证，存在 iPhone 的钥匙串里。
- 发布给别人用的版本：一把用来解开通知的密钥，也在钥匙串里。
- 语言、字号这类设置，还没发出的消息，以及你存的常用语。
- 你打开过的聊天的副本，打开时就能马上显示：只留 30 天内打开过的，每个只留最新的一段。「设置 → 存储」里能看到
  占多大，也能清除;退出登录会删掉那台 Mac 的。

删掉 App,设置、草稿、常用语和聊天副本就没了。钥匙串里的条目，App 删掉后 iOS 可能还留着;在 App 里退出登录会删掉它的登录凭证。

## 发到你 Mac 上的

你在 App 里看到和发出的一切：会话、消息、图片、文件，以及语音转成的文字。你的 Mac 怎么存它们，见
[配置](configuration.zh-CN.md)。语音由 iOS 的语音识别转成文字，适用苹果的条款。

## 发到别处的

- **通知。** 你的 Mac 通过苹果的推送服务发出通知。发布给别人用的版本，通知会先经过发布者的中转，用你手机上的
  密钥加了密：中转只看得到你设备的推送令牌、通知什么时候发、有多大，看不到内容，也什么都不留。
- **App 更新。** 发布给别人用的版本，从发布者的服务器下载 JavaScript 更新，那台服务器看得到你的 IP 地址和
  App 的版本，跟任何网站一样。你自己编译的版本从你的 Mac 下载更新。
